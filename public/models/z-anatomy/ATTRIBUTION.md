# Z-Anatomy assets

This directory contains anatomy system models from **Z-Anatomy — the libre 3D atlas of anatomy** by Gauthier Kervyn, Marcin Zielinski, and Lluís Vinent Juanico.

Source: https://github.com/LluisV/Z-Anatomy/tree/PC-Version/Resources/Models/FBX
